対象の設定

    

      処理する言語・フォルダ・ファイル・除外を決めます。保存先 
      （夜間バッチ・コマンドからの実行にも反映されます）。
    

    

      いまは例の設定（targets.example.toml）が使われています。保存すると targets.toml が作られ、以後そちらが使われます。
    

    

      パターンの書き方
      

        
*/ を含まない任意の文字列（例: *_test.go）

        
?/ 以外の1文字（例: ?*_api … _api の前に1文字以上）

        
[abc] [!abc]いずれか1文字・いずれでもない1文字

        
**/0個以上のフォルダ（例: **/vendor/**）

        
/**（末尾）そのフォルダの下のすべて（サブフォルダを含む）

      

      
パターンは対象フォルダからの相対パス（/ 区切り）全体と照合します。除外は対象より優先されます。
        \・先頭の /・.. は書けません。大文字と小文字は区別します。include は対象フォルダ名を先頭に付けたパスとも照合します。

    

    
すべての言語に共通の除外 （1行に1つ）

スキル

    

      SKILL.md のあるフォルダ（参照ファイルを含む）を選ぶと、まとめて登録します。SKILL.md だけを登録することもできます。
      登録したスキルは「実行」タブ・定期実行のプルダウンで選べます。コマンドからの実行でも --tasks スキル名 で使えます。
      直前のスキルは1世代だけ残り、「直前に戻す」で戻せます。
